# HSKWealthDelta

Colony wealth diary. Advanced colony wealth tracking mod.

Ever looted a bunch of stuff and watched your colony wealth skyrocket? Always wanted to know exactly what junk you picked up — now you can.

## Features

- Track wealth changes per day, quadrum, or year
- 2 modes:
  - View changes over the last N days
  - View changes between specific days
- See which items, buildings, and pawns were added or removed
- Categorized view: all, items, buildings, pawns
- Draggable wealth widget overlay
- Sortable columns (name, count, value)
- Collapsible groups (weapons, apparel, food, textile, etc.)

Ежедневник стоимости колонии. Прокачанный мод для подсчёта стоимости колонии.

У вас же бывает такое, что вы чего-то налутали вчера и стоимость вашей колонии выросла на огромное число? Всегда хотелось посмотреть какого мусора насобирал — теперь можно.

## Особенности

- Отслеживание изменений богатства за день, квартал или год
- 2 режима:
  - Посмотреть изменения за N дней
  - Посмотреть изменения между определёнными днями
- Показывает какие предметы, здания и пешки появились или исчезли
- Категории: все, предметы, здания, пешки
- Перемещаемый виджет богатства
- Сортировка по имени, количеству, стоимости
- Сворачиваемые группы (оружие, одежда, еда, текстиль и др.)
